# Sonrisa Imperial

Landing page de la clínica dental **Sonrisa Imperial**. Su único objetivo es que los pacientes agenden una cita.

## Estructura

```
├── index.html      → contenido de la página
├── css/styles.css  → diseño (colores, tipografías, acomodo)
└── js/main.js      → lógica del formulario
```

## Cómo verla

Abre `index.html` en tu navegador. No necesita instalar nada.

## Agendar citas

Al enviar el formulario se abre WhatsApp con la solicitud lista. El número de la clínica se cambia en `js/main.js` (`WHATSAPP_NUMERO`).
